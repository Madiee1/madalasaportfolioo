Add these image files here before deploying:

- profile.jpg        -> your photo, used in the About section (falls back to an "M" mark if missing)
- og-cover.png        -> a 1200x630 image used when the site is shared on social media (Open Graph)

Any project screenshots referenced from the admin API (Project.imageUrl) can also live in this folder,
e.g. assets/images/projects/hostel-management.png — then set imageUrl to that relative path.
